# Applied Natural Language Processing – Lecture Series

This repository serves as the **main entry point** for all weekly materials of the course *Applied NLP*.  
Each week has its own dedicated repository containing slides, notebooks, and exercises.  
This course was originally designed for bachelor’s students in **Computer Science** program.
